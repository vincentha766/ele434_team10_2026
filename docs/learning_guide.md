## 1. ROS2 基础架构

项目用到了 ROS2 的三大核心机制：

| 机制 | 代码位置 | 作用 |
|------|---------|------|
| **话题订阅** | `/scan`, `/odom`, `/map` | 接收传感器数据 |
| **话题发布** | `/cmd_vel` | 发送速度指令 |
| **TF 变换** | `map → base_footprint` | 获取 SLAM 校正后的全局位姿 |

### 关键概念
- `rclpy.spin_once()` — 非阻塞地处理一次回调，`work.py:298` 用它实现约 20Hz 的控制循环
- **回调函数** — 传感器数据到达时自动触发（如 `work.py:49-94`）

## 2. 激光雷达 (LiDAR) 使用

LiDAR 是最核心的感知传感器。TurtleBot3 Waffle 的 LDS-01 提供 **360 度扫描数据**。

### 数据结构
```python
# LaserScan.ranges = [r0, r1, ..., r359]
# 索引 0 = 正前方, 逆时针递增
# 值 = 该角度的障碍物距离 (米)
```

### 数据清洗（`work.py:66-81`）
```python
# 真实雷达会有 nan、inf、贴脸噪点，必须过滤
if math.isnan(r) or math.isinf(r) or r < 0.05:
    cleaned_ranges.append(3.5)  # 视为空旷
```

### 扇区划分（`work.py:376-386`）
将 360 度分成 8 个 45 度扇区，取每个扇区的最小值判断危险方向：
```
         正前 (337-22度)
    左前 /          \ 右前
  正左 |    机器人    | 正右
    左后 \          / 右后
         正后
```
这样你就知道障碍物在哪个方向、有多远。

## 3. 避障算法

代码实现了 **Bug-0 弧形绕障**，这是一种反应式避障：

### 状态机设计（`work.py:399-455`）
```
+----------+  前方安全    +----------+
|  ALIGN   | ----------> |  DRIVE   |
| 原地对准  | <---------- | 直行前进  |
+----+-----+  角度偏大    +----+-----+
     |                         |
     |  前方危险 (< 0.32m)      |
     +---------+---------------+
               v
         +----------+
         |  AVOID   |
         | 弧形绕障  |
         +----------+
```

### 核心思路
1. **进入避障**: `min_f < SAFE_RADIUS` (正前方距离 < 0.32m)
2. **选择方向**: 优先朝目标方向转，但如果那一侧更窄就转反方向
3. **弧形绕行**: 小线速度 + 大角速度 = 绕着障碍物走弧线
4. **退出条件**: 已转够角度且前方清空，或障碍物已被绕过

### obstacle.py 基础避障示例
```python
def juggment(self, dist):
    lon = len(dist)
    i = lon / 360

    # 正前方扇区 (约 +-22度)
    front = dist[0:int(22*i)] + dist[int(338*i):]
    min_front = min(r if r > 0.05 else 3.5 for r in front)

    if min_front < 0.35:       # 前方有障碍
        if min(dist[int(45*i):int(135*i)]) > min(dist[int(225*i):int(315*i)]):
            self.turn(0.5)     # 左边更空，左转
        else:
            self.turn(-0.5)    # 右边更空，右转
    else:
        self.move(0.2)         # 前方安全，直行
```

## 4. 路径规划 (A* 算法)

`work.py:119-149` 实现了基于占据栅格的 A* 寻路。

### 流程
```
世界坐标 (x,y) -> 栅格坐标 (col,row) -> A* 搜索 -> 栅格路径 -> 世界路径
```

### 关键步骤
1. **占据栅格** — Cartographer SLAM 输出 `/map`，每个格子的值：
   - `-1` = 未知区域
   - `0` = 确认空旷
   - `100` = 确认有障碍
2. **障碍膨胀** (`work.py:106-117`) — 将障碍物向外扩展机器人半径的距离，这样规划时可以把机器人当成一个点
3. **A* 搜索** — 8 连通（含对角线），用欧几里得距离作为启发函数
4. **渐进回退** (`work.py:160-194`) — 膨胀半径从大到小尝试，先安全后激进

## 5. 覆盖探索策略

任务是让小车进入所有 12 个 1x1m 格子。

### 航点序列（`work.py:240-258`）
预定义 17 个航点（12 个得分格 + 5 个枢纽点），按顺时针顺序走一圈。

### 机会式打分（`work.py:343-347`）
不管当前目标是哪个航点，只要车身进入任何得分格（`|x-cx| <= 0.5 且 |y-cy| <= 0.5`），就标记该格已完成。

### 防卡检测（`work.py:324-337`）
20 秒内位移不到 5cm -> 判定为卡住，停车。

## 6. 定位：里程计 vs SLAM

| 方法 | 话题/TF | 优点 | 缺点 |
|------|---------|------|------|
| **里程计** `/odom` | 快速、始终可用 | 轮子打滑会累积漂移 |
| **SLAM TF** `map->base_footprint` | 全局精确，消除漂移 | 需要 Cartographer 运行 |

代码优先用 SLAM（`work.py:307-317`），失败时回退到里程计。
